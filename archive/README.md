# Archived — previous ResonantOS website (Astro)

This folder preserves the previous version of the ResonantOS marketing website that
was live at resonantos.com before the 2026-09-03 relaunch on the baseplate narrative.

## What is here

- `astro-src/` — the Astro + Tailwind source of the old site (`src/pages/*.astro`,
  `public/` assets). It told the older "Augmentor-centric, browser-first product"
  story and was dark-only.
- `resonantos-website.zip` — a full snapshot of that repository.
- Build configs and handover docs (`package.json`, `astro.config.mjs`,
  `netlify.toml`, `vercel.json`, `HANDOVER.md`, `COMPLETION_SUMMARY.md`,
  `DEPLOYMENT.md`, `LIGHT_THEME_CHANGES.md`).

The complete git history of the old site is also preserved in this repository's
history (commits before the 2026-09-03 static relaunch).

## Why

The 2026-09-03 relaunch replaced the site with a single self-contained static page
(`../index.html`) telling the agreed architecture story: ResonantOS as the neutral
baseplate for composable intelligence, in the ResonantDAO visual system, with light
and dark themes and Discord/DAO calls to action.
